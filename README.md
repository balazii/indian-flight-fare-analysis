# Indian Flight Fare Analysis and Prediction

**Student:** Podisetty Balaji  
**Course:** Artificial Intelligence  
**Project format:** Jupyter notebook with Python source export

## Project overview

Explore historical Indian flight listings to describe fare distributions and variation across airlines, routes, booking windows, duration, stops, departure timing, and travel class, then build a reproducible fare-prediction baseline.
