# Publish this folder on GitHub

This package is ready to upload, but it has not been published to a GitHub account. Sign in to GitHub and create a repository named `indian-flight-fare-analysis`. Choose the visibility required by your instructor. If the repository must be public, review the files first because the notebook header contains your course email.

From this folder, run:

```bash
git init
git add .
git commit -m "Add Indian Flight Fare Analysis and Prediction project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/indian-flight-fare-analysis.git
git push -u origin main
```

If Git asks for a commit identity, set it for this repository only. For public repositories, prefer the GitHub-provided `noreply` email if you do not want your school email exposed in commit history.
